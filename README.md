# 🎯 Quiz App

A browser-based quiz platform with 4 subjects: GK, English, Aptitude, and Logical Reasoning.

## Features
- Subject selection screen
- 10 questions per subject
- Instant correct/wrong feedback
- Final score and percentage

## How to Play
1. Open `index.html` in a browser
2. Select a subject
3. Answer all 10 questions
4. See your score!
